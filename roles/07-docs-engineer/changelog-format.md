# CHANGELOG Format — Docs Engineer

## Format (Keep a Changelog)

```markdown
# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added
- Feature X for doing Y (#kata-001)

### Changed
- Improved Z behavior (#kata-002)

### Fixed
- Bug in W module (#kata-003)

### Removed
- Deprecated feature V (#kata-004)
```

## Rules

1. One entry per kata
2. Reference kata ID in parentheses
3. Group by type: Added, Changed, Fixed, Removed, Deprecated, Security
4. Date-stamp releases
5. No external links (offline constraint)
